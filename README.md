# Pemrograman Berbasis Web Lanjut 3C

Repositori ini berisi kumpulan proyek Laravel mahasiswa untuk mata kuliah Pemrograman Berbasis Web Lanjut (PBWL) kelas 3C.

## Struktur

Setiap folder dengan format berikut merupakan project aplikasi Laravel mandiri milik mahasiswa:

- `250441100xxx-NAMA_MAHASISWA`

## Tujuan

- Menyimpan hasil pengerjaan tugas praktikum
- Menjaga agar setiap proyek mahasiswa terpisah dan tidak saling tertukar
- Memudahkan pengelolaan repo monorepo untuk praktikum

## Catatan

- Jangan mengubah file di luar project mahasiswa kecuali file konfigurasi repo yang memang dibutuhkan
- Pastikan setiap project tetap berdiri sendiri dan mengikuti struktur Laravel yang berlaku
